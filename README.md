# 윤성수 한의원 홈페이지

한의사 윤성수 한의원의 정적 홈페이지입니다. 빌드 과정 없이 HTML, CSS, JavaScript 파일로 구성되어 있습니다.

## 파일 구성

- `index.html` — 페이지 구조와 내용
- `style.css` — 디자인 (라이트/다크 모드 자동 대응, 모바일 대응)
- `script.js` — 푸터 연도 자동 갱신

## 미리보기

브라우저에서 `index.html` 파일을 열면 바로 확인할 수 있습니다.

로컬 서버로 확인하려면:

```bash
python3 -m http.server 8000
```

그 다음 http://localhost:8000 에 접속하세요.

## 채워야 할 정보

`index.html`에서 아래 항목을 실제 정보로 바꿔 주세요.

- 원장 학력, 경력, 전문 분야 (원장 소개)
- 진료 과목 3개의 이름과 설명 (진료 안내)
- 진료 시간 (`00:00` 표시된 부분)
- 주소, 교통 및 주차 안내, 지도 (오시는 길)
- 전화번호와 이메일 (연락처)

## 의료 광고 관련 주의

한의원 홈페이지는 「의료법」과 의료광고 심의 기준의 적용을 받습니다. 치료 효과를 단정하거나 과장하는 표현(예: "완치", "100% 효과", "최고")은 피하고, 게재 전 관련 기준을 확인해 주세요.
